# Source map: web → Swift → Rust

This file maps the rowplay web app (canonical behaviour) and rowplay-studio
(second reference) onto rowplay-qt, and records every deliberate divergence.
When the web and Swift versions disagree, the web wins unless Studio's source
map documents a deliberate deviation; the "Divergences" section lists what the
Rust port chose and why.

## Phase 5a — replay assets and scene

The vendored replay packs, their contract validation and the static scene.
`build.rs` converts both packs with Qt's `balsam` into a generated
`RowPlay.ReplayAssets` QML module (ADR 0008); `rowplay_viewmodel::replay`
holds the Qt-free contract reader, material roles, venue palette and anchor
table; the `Replay` singleton in `rowplay-app/src/backend/replay.rs` is a
thin adapter over them. Playback, the chase camera and the HUD are Phase 5b,
the quality tiers Phase 5c.
